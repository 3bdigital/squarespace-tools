1. A text block, styled in Squarespace

The markup below is what a Squarespace text block looks like. The numbers are typed as {{101}} inside ordinary styled text. Put the whole finished display inside the braces, {{1,000+}}, so the reserved width covers the suffix too.

{{101}}
Countries in which Field has operated

${{6}}bn+
Highest transaction value

{{1,000+}}
Projects conducted

1b. Options inside the marker

Anything after a pipe sets the same options the attributes do, without the data-counter- prefix. A bare time is the duration.

{{101 | 5s}} {{101 | 5s}}
{{1,000,000,000 | 4s step=10000000}} {{1,000,000,000 | 4s step=10000000}}
staggered: delay=0 / 300ms / 600ms {{10}} {{10 | delay=300ms}} {{10 | delay=600ms}}
{{12.5 | suffix="%" fps=4}} {{12.5 | suffix="%" fps=4}}
{{101 | colour=red}} (unknown option ignored) {{101 | colour=red}}

1c. A Squarespace code block

A code block is .sqs-block-code, and it renders your HTML. Both forms work in one. The element form cannot flash, because the finished number is already in the markup.

$6bn+
Highest transaction value
{{$6bn+}}
Highest transaction value, marker form
